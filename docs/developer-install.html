Developer / Windows

Dari source ke installer StarGate

Clone proyek, siapkan kebutuhan build, lalu hasilkan installer yang bisa dipasang di laptop pengguna.

Panduan ini untuk developer yang membangun StarGate di Windows 11 x64, termasuk komputer dengan prosesor AMD x64. Build Windows dijalankan di Windows. Jika mengembangkan di Mac, gunakan Windows melalui VM atau komputer Windows untuk langkah build.

Persiapan pada langkah 1–5 cukup dilakukan sekali. Untuk build berikutnya, langsung ke Build setelah perubahan.

Perintah membutuhkan internet saat mengambil source, library, dan model. Laptop pengguna nantinya cukup menerima installer.

1. Alat yang diperlukan

Pasang alat berikut di komputer untuk build. Gunakan versi x64.

AlatKebutuhan
Python 3.11Menjalankan kode dan menyiapkan environment.
GitMengambil dan memperbarui source proyek.
Visual Studio Build ToolsPilih Desktop development with C++. Dibutuhkan untuk pgvector dan library yang perlu dikompilasi.
PostgreSQL 17Sumber runtime database yang akan dibawa installer.
Inno Setup 6Membuat file installer .exe.
Visual C++ Redistributable x64Runtime untuk library native Windows.

Visual C++ Redistributable dan Build Tools memiliki fungsi berbeda. Redistributable saja tidak menyediakan compiler nmake.

2. Clone proyek

Buka PowerShell. Ganti <URL_REPOSITORI_ANDA> dengan URL Git proyek ini.

PowerShell
git clone <URL_REPOSITORI_ANDA> StarGate
cd StarGate

Jalankan perintah PowerShell berikutnya dari folder proyek, kecuali ada instruksi untuk berpindah terminal.

3. Environment Python

Buat environment khusus proyek, lalu pasang PyTorch versi CPU sebelum library lainnya. Dengan begitu, build tidak mengambil paket GPU yang tidak dibutuhkan.

PowerShell · folder proyek
py -3.11 -m venv .venv-win
.\.venv-win\Scripts\python.exe -m pip install "torch>=2.6,<3" --index-url https://download.pytorch.org/whl/cpu
.\.venv-win\Scripts\python.exe -m pip install -r requirements.in
.\.venv-win\Scripts\python.exe -m pip check

Pemeriksaan terakhir seharusnya menampilkan No broken requirements found. Perintah menggunakan Python dari environment secara langsung, sehingga tidak perlu aktivasi environment.

4. Ambil model AI

Bobot model tidak ikut Git. Script berikut mengunduh model yang tercatat di manifest dan memeriksa checksum untuk memastikan berkas sesuai.

PowerShell · folder proyek
.\.venv-win\Scripts\python.exe scripts/download_models.py

Tunggu sampai selesai sebelum build. Paket dengan model saat ini mengikuti penggunaan lomba, penelitian, dan pengujian internal. Lihat notice dependency dan model sebelum distribusi komersial.

5. Siapkan runtime database

Installer membawa PostgreSQL dan pgvector supaya pengguna tidak perlu menyalakan database secara manual. Siapkan folder runtime ini satu kali, lalu gunakan kembali untuk build berikutnya.

Pasang pgvector pada PostgreSQL

Buka x64 Native Tools Command Prompt dari Visual Studio Build Tools, dengan hak untuk memasang extension ke direktori PostgreSQL. Terminal pada langkah ini menggunakan CMD, bukan PowerShell.

x64 Native Tools Command Prompt · CMD
git clone --branch v0.8.7 --depth 1 https://github.com/pgvector/pgvector.git C:\StarGate-pgvector
set "PGROOT=C:\Program Files\PostgreSQL\17"
cd /d C:\StarGate-pgvector
nmake /F Makefile.win
nmake /F Makefile.win install

Jika PostgreSQL terpasang di lokasi lain, sesuaikan PGROOT dan path pada perintah berikut. Panduan upstream tersedia di dokumentasi pgvector.

Kemas runtime untuk installer

Kembali ke PowerShell di folder proyek. Perintah ini mengambil lisensi PostgreSQL lalu menyalin runtime dan lisensinya ke folder baru.

PowerShell · folder proyek
New-Item -ItemType Directory -Force .local | Out-Null
Invoke-WebRequest 'https://raw.githubusercontent.com/postgres/postgres/REL_17_STABLE/COPYRIGHT' -OutFile '.local\postgresql-COPYRIGHT'
.\.venv-win\Scripts\python.exe scripts/prepare_postgres_runtime.py --source 'C:\Program Files\PostgreSQL\17' --output 'C:\StarGate-runtime\postgresql' --postgres-license '.local\postgresql-COPYRIGHT' --pgvector-license 'C:\StarGate-pgvector\LICENSE'

Output harus berupa folder baru. Setelah berhasil, folder C:\StarGate-runtime\postgresql berisi runtime-manifest.json. Proses ini menyalin program database, bukan isi database pengguna.

6. Build installer

Setelah environment, model, dan runtime siap, jalankan:

PowerShell · folder proyek
.\packaging\windows\build.ps1 -IncludeResearchModels -PostgresRuntime 'C:\StarGate-runtime\postgresql'

Script menjalankan PyInstaller, menyertakan ikon StarGate, memeriksa paket dan model, lalu membuat installer dengan Inno Setup. Jika pemeriksaan gagal, script berhenti sebelum membuat installer.

HasilLokasi
Aplikasi hasil builddist\StarGate\StarGate.exe
Pertahankan seluruh folder dist\StarGate jika menjalankan hasil ini langsung.
Installer untuk penggunadist\installer\StarGate-Research-Windows-x64.exe

Kirim file installer ke laptop tujuan. Jangan mengambil StarGate.exe sendirian dari folder build karena aplikasi membutuhkan berkas di sekitarnya.

7. Install di laptop tujuan

  1. Jalankan StarGate-Research-Windows-x64.exe dan ikuti proses pemasangan.
  2. Buka StarGate dari Start Menu.
  3. Pada penggunaan pertama, buat akun Super Admin.
  4. Klik kanan ikon StarGate saat berjalan, lalu pilih Pin to taskbar.

Laptop pengguna tidak perlu Python, Git, Build Tools, atau Inno Setup. Database lokal dinyalakan saat StarGate dibuka. Model dimuat ketika registrasi wajah atau absensi dimulai.

Data aplikasi berada di %LOCALAPPDATA%\StarGate, terpisah dari berkas program. Setelah restart Windows, buka StarGate kembali dari shortcut atau taskbar.

Periksa hasil pemasangan

  • Login, kemudian buka halaman anggota dan perangkat.
  • Buka kamera, lakukan registrasi wajah, lalu coba absensi.
  • Tutup aplikasi, restart Windows, lalu pastikan login, data, kamera, dan model tetap berfungsi.

Build yang selesai tetap perlu diuji di laptop tujuan. Pengujian VM Parallels belum menggantikan pengujian langsung pada perangkat AMD tersebut.

Build setelah perubahan

Tutup StarGate yang berjalan dari folder build. Jika mengambil pembaruan dari Git, simpan atau commit perubahan lokal terlebih dahulu, lalu jalankan git pull.

Dengan environment, model, dan runtime yang masih tersedia, jalankan lagi:

PowerShell · folder proyek
.\packaging\windows\build.ps1 -IncludeResearchModels -PostgresRuntime 'C:\StarGate-runtime\postgresql'

Jika dependency atau manifest model berubah, ulangi langkah pemasangan library atau pengunduhan model sebelum build. Bagikan installer yang baru dihasilkan.

Jika terjadi error

Python 3.11 tidak ditemukan

Pastikan Python 3.11 x64 dan Python Launcher terpasang. Periksa daftar Python dengan py -0p, lalu buka terminal baru setelah instalasi.

nmake tidak dikenali

Jalankan langkah pgvector di x64 Native Tools Command Prompt. Pastikan komponen Desktop development with C++ sudah terpasang.

runtime-manifest.json tidak ditemukan

Selesaikan langkah 5 dan periksa lokasi output runtime. Nilai -PostgresRuntime harus menunjuk folder yang memuat manifest tersebut.

PowerShell menolak menjalankan script

Gunakan kebijakan menjalankan script yang diizinkan di komputer Anda. Pada perangkat yang dikelola organisasi, hubungi pengelolanya.

Inno Setup tidak ditemukan

Pasang Inno Setup 6. Script mencari ISCC.exe melalui PATH dan lokasi instalasi standar per pengguna atau sistem.

Package check gagal atau non-zero exit status

Baca hasil pemeriksaan sebelum baris terakhir. Nilai false menunjukkan pemeriksaan yang gagal; kode exit saja belum menjelaskan penyebabnya. Salin bagian error dan perintah yang gagal saat melaporkan masalah, tanpa menyertakan password atau isi .env.

Membersihkan storage

Setelah aplikasi dan proses build ditutup, folder build/ serta keluaran dist/ yang tidak dipakai boleh dihapus. Simpan satu installer terbaru jika masih dibutuhkan.

Pertahankan .venv-win/, model, dan runtime PostgreSQL jika akan build lagi. Tidak perlu membuat salinan source, wheelhouse, atau ZIP proyek untuk setiap pembaruan.

Jangan menghapus database, foto anggota, .env, atau cadangan untuk membersihkan hasil build. Itu data aplikasi, bukan cache.

Panduan ini mengikuti dokumentasi build Windows dan script packaging/windows/build.ps1 di proyek. Untuk penggunaan aplikasi, baca panduan operasional.
