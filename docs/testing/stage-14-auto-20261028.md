# Tahap 14: installer dengan database otomatis

Tanggal: 28 Oktober 2026. Pengujian dilanjutkan setelah VM dapat dinyalakan. Kandidat: **0.14.1-research**, aplikasi x64 pada Windows 11 ARM64 Parallels. Komputer AMD fisik customer belum diuji.

## Cakupan dan isolasi

Build memakai sumber terbaru dari proyek, termasuk perubahan antarmuka dan alur akun yang dibuat setelah installer 20 Oktober. PostgreSQL 17.11 x64 dan pgvector 0.8.7 disertakan dalam paket. Model tetap untuk lomba, penelitian, dan pengujian internal.

Pengujian memakai akun Windows standar terpisah `SGAuto28`. Database baru memakai listener loopback dan folder milik akun tersebut. Akun utama dan database kerja Mac tidak menjadi sasaran setup, seed, uninstall, atau restore. Data sekolah yang digunakan bersifat fiktif; pengujian ini tidak menyimpan wajah nyata.

Alat pendamping `windows_auto_frozen_uat.py` hanya untuk pembuktian pada akun uji. Alat tersebut memakai modul aplikasi hasil build dan dependensi paket yang sama, lalu menjalankan alur UI dengan Qt offscreen. Alat pendamping tidak disertakan dalam installer customer. Ini tidak menggantikan uji klik dan kamera pada layar Windows customer.

## Perbaikan

- Pengunci setup Windows menggunakan ukuran berkas melalui `fstat`, sehingga proses kedua tidak membaca byte yang sedang dikunci proses pertama.
- Tes berkas privat memeriksa DACL pada Windows. Tes symlink dilewati saat token standar tidak memiliki hak membuat symlink.
- Installer mengembalikan exit code gagal jika penyiapan database atau pemeriksaan paket gagal. Pesan gagal dapat ditekan saat pengujian silent agar proses tidak menunggu dialog.
- Hasil penyiapan dan pemeriksaan paket dimasukkan ke log Inno Setup. Penghentian database saat uninstall memiliki `RunOnceId` agar entri duplikat tidak diulang.
- Installer menghentikan database kelolaannya melalui `PrepareToInstall` sebelum mengganti berkas. Jika penghentian gagal, pemasangan berhenti sebelum penyalinan. Konfigurasi eksternal tanpa penanda cluster kelolaan melewati langkah tersebut.

Pencatatan installer mengikuti dokumentasi resmi Inno Setup yang diperiksa melalui Context7: [ExecAndLogOutput dan fungsi terkait](https://github.com/jrsoftware/issrc/blob/main/Projects/Src/Shared.ScriptFunc.pas). Akun uji dijalankan melalui API Windows dengan profile dan environment sendiri, tanpa password pada command line; [CreateProcessAsUserW](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessasuserw) dan [LoadUserProfileW](https://learn.microsoft.com/en-us/windows/win32/api/userenv/nf-userenv-loaduserprofilew).
