# Lebar sidebar

Sidebar diperlebar dari 224 menjadi 272 px sesuai permintaan pengguna. Tambahan 48 px memberi ruang untuk menu panjang seperti Cadangan dan pemulihan, termasuk padding dan scrollbar vertikal bila diperlukan. Scrollbar horizontal tidak disembunyikan paksa; konten menu benar-benar diperiksa agar muat.

Arah tetap mengikuti tema hijau, font sistem dan dial StarGate sebelumnya (ENERGY 1 / RHYTHM 2 / MOTION 1). Tidak mengubah daftar menu, warna, tombol akun, atau cara navigasi.

Delivery Gate revisi: PASS, semua menu Super Admin dipilih pada jendela 1000×740, 1180×820 dan 1440×900 menggunakan shell Qt offscreen. Nilai maksimum scrollbar horizontal navigasi selalu nol, dan lebar teks beserta padding 30 px tidak melebihi viewport. Render ditinjau dan label menu terlihat utuh. PASS, Purpose-Gate karena perubahan ukuran langsung memberi ruang untuk nama menu yang ada. PASS, Liveliness dan Craftsmanship karena tema/urutan kerja dipertahankan serta seluruh menu tetap dapat dipilih. Tidak ada aset atau klaim baru.

Bukti: `evidence/sidebar-width.png`. Gambar memakai shell dengan halaman placeholder dan akun sintetis untuk memeriksa sidebar; bukan tampilan dashboard operasional terbaru. Tidak membuka kamera atau database.
